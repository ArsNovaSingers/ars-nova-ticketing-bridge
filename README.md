# ars-nova-ticketing-bridge

**Ars Nova Singers - custom WordPress plugin.** Canonical source (private use; not distributed).

- Current version: 1.0.0 (matches DEV arsnovasingers.kinsta.cloud; header reports 1.0.0)
- Environment: DEV only; not on LIVE.
- Admin-only REST endpoints to create and list Tickera events and Bridge ticket-type WooCommerce products by command. v1.0.0.

Releases: each tag v<version> attaches the installable zip (top folder ars-nova-ticketing-bridge/). Install/update via the Ars Nova Ops installer or WP-admin upload.
